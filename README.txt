# The Lost Kingdom: Forest Quest

## Files
- `main.py`: Starts the game and connects the modules.
- `player.py`: Player health, inventory, potions, and equipment.
- `world.py`: Map, movement, monster locations, and items.
- `actions.py`: Combat, NPC dialogue, and quest progress.

## Run the game
Keep all four Python files in the same folder. Open a terminal in that folder and run:
`python main.py`
(Use `python3 main.py` if needed.)

## Controls
W/A/S/D = move; I = inventory; P = potion; E = equip weapon;
T = talk to Elder (stand on E); Q = quest; H = status; X = quit.
In battle: A = attack; P = potion; R = run.

## Goal
Talk to the Elder and accept the quest, collect 3 moon crystals, and defeat the Shadow Dragon.
